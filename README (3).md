# اپلیکیشن خرید و فروش تتر

اپلیکیشن وبی که کاربر پس از ثبت‌نام می‌تواند تتر (USDT) را با قیمت لحظه‌ای بخرد یا بفروشد؛ مشابه پلتفرم‌های خرید و فروش طلا یا ارز دیجیتال.

---

## استک فنی

- **Backend:** Node.js, Express, TypeScript
- **Database:** MongoDB (Mongoose), روی MongoDB Atlas
- **Cache:** Redis, روی Redis Cloud
- **Auth:** JWT + bcryptjs
- **Validation:** Zod
- **Frontend:** HTML / CSS / JavaScript خالص (بدون فریم‌ورک)، به‌همراه Chart.js برای نمودارها

---

## ساختار پوشه‌ها

```
exchange/
├── public/              فایل‌های فرانت (HTML, CSS, JS)
├── src/
│   ├── config/          اتصال به دیتابیس و Redis
│   ├── controllers/     منطق اصلی هر مسیر
│   ├── middlewares/     احراز هویت، اعتبارسنجی، مدیریت خطا
│   ├── models/          ساختار داده‌های Mongoose
│   ├── routes/          تعریف مسیرها
│   ├── services/        منطق مستقل (قیمت لحظه‌ای)
│   ├── utils/           ابزارهای کمکی (خطا، wrapper)
│   ├── validators/      ساختارهای اعتبارسنجی Zod
│   └── index.ts         فایل ورودی اصلی
├── .env                 متغیرهای محیطی (در گیت قرار نمی‌گیرد)
├── package.json
└── tsconfig.json
```

## راه‌اندازی محلی

### ۱. نصب پیش‌نیازها

```bash
npm install
```

### ۲. تنظیم فایل `.env`

یک فایل `.env` در ریشه‌ی پروژه بسازید و مقادیر زیر را با اطلاعات واقعی خودتان پر کنید:

```
MONGODB_URI=mongodb+srv://<user>:<pass>@<cluster>.mongodb.net/?appName=Cluster0
REDIS_URL=redis://default:<pass>@<host>:<port>
JWT_SECRET=<یک رشته‌ی تصادفی طولانی و امن>
```

### ۳. اجرای سرور در حالت توسعه

```bash
npm run dev
```

سرور روی آدرس زیر بالا می‌آید:

```
http://localhost:3000
```

فرانت به‌صورت خودکار از همین آدرس سرو می‌شود (فایل‌های پوشه‌ی `public`).

### ۴. بیلد برای production (اختیاری)

```bash
npm run build
npm start
```

## قابلیت‌ها

- ثبت‌نام و ورود با ایمیل/رمز عبور، احراز هویت با JWT
- ساخت خودکار کیف پول (موجودی تومانی + تتر) هنگام ثبت‌نام
- نمایش قیمت لحظه‌ای تتر (شبیه‌سازی‌شده با نوسان تصادفی، کش‌شده در Redis)
- خرید و فروش با بررسی موجودی کافی
- تاریخچه‌ی تراکنش‌ها با صفحه‌بندی
- نمودار قیمت لحظه‌ای (خط پله‌ای) و نمودار تراکنش‌ها (میله‌ای)
- مدیریت خطای متمرکز و اعتبارسنجی ورودی با Zod

---

## نکات مهم

- قیمت لحظه‌ای واقعی از صرافی گرفته نمی‌شود؛ به دلیل یک مشکل شبکه/دسترسی، یک سرویس شبیه‌ساز جایگزین آن شده که رفتار نوسان بازار را تقلید می‌کند.
- افزایش موجودی تومانی کاربر (واریز) در این نسخه فقط از طریق ویرایش دستی در دیتابیس ممکن است؛ درگاه پرداخت واقعی پیاده‌سازی نشده (خارج از محدوده‌ی این نسخه‌ی آموزشی).
- هیچ‌گاه فایل `.env` را در گیت commit نکنید (در `.gitignore` قرار دارد).
